# 02 - Calculadora de IR Brasileiro

Módulo de cálculo de Imposto de Renda: tabela regressiva pra renda fixa (22,5% / 20% / 17,5% / 15% conforme prazo), isenção de R$20.000/mês para ações individuais, 15% sem isenção para ETF/BDR, 20% sem isenção para FII. Precisa de preço médio por ativo (custo médio ponderado) calculado a partir do histórico de transações.
